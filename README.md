# Kapsama

Güncel mobil uygulama **Kapsama20** klasöründedir. Android Studio'da bu klasörü açın.

- [Güncel uygulamanın kurulumu ve Supabase ayarları](Kapsama20/README.md)
- Minimum Android sürümü: API 28 (Android 9).
- Supabase bağlantısı için kendi `Kapsama20/local.properties` dosyanızı ayarlayın; bu dosya Git'e eklenmez.

## Depodaki iki Android projesi

| Konum | İçerik |
| --- | --- |
| `Kapsama20/` | Jetpack Compose uygulaması: öğrenci girişi, sinyal ekranı, çevrimdışı gönderim kuyruğu ve ödev listesi. |
| Kök `app/`, `gradle/` ve Gradle dosyaları | Önceki XML prototipi. Sabit örnek ölçümler ve ayrı Supabase bağlantısı içerir; gerçek cihaz ölçümü yapmaz. |

Hackathon sunumu için **Kapsama20** projesini çalıştırın. İki proje farklı uygulama kimlikleri kullanır.
